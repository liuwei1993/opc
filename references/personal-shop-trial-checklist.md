# 个人网店试错检查清单

> 来源：2026-08-31 与无限的对话 + 最新平台规则调研
> 适用：零电商经验、有产品能力（代码/服务/课程）、低成本验证市场
> 底线原则：**第一个月投入 ≤1000 元（基本只有保证金）；任何"先交钱学开店/买流量包"的都是骗子**

---

## 一、核心认知（破除迷思）

1. **行业壁垒是错觉**：开店准入是史上最低（淘宝个人身份证即可、闲鱼零门槛、微店几乎零门槛）。真正的壁垒是流量获取 + 规则熟练度 + 交付稳定性，不在准入。
2. **"卷"的是低价实物，不是虚拟商品/服务**：卖软件、定制、咨询、课程的边际成本趋近于零，不跟供应链玩家卷。
3. **最大的坑"仅退款"已被监管填平**：2025-04-22 淘宝/拼多多/抖音/快手/京东集体取消或大幅调整"仅退款"，改为商家自主协商（拼多多给 36 小时处理期）。
4. **平台费率只会涨不会跌**：闲鱼三年三变（2023 高频卖家 1% → 2024 全体 0.6% → 2026 鱼小铺统一 1.6% 且取消门槛、退款不退费）。商业模式不要建立在"平台永远免费"的假设上。

## 二、平台速查表（2026-08 状态）

| 平台 | 门槛 | 费用 | 适合阶段 |
|---|---|---|---|
| 闲鱼 | 零门槛，实名即可 | 个人偶尔卖免服务费（月≤10笔且≤1万）；鱼小铺 1.6% | 试水起步 |
| 微店 | 几乎零门槛 | 按成交抽成 | 微信私域承接 |
| 淘宝 | 身份证开店，保证金按类目（虚拟类 500-1000 元，可退） | 佣金成交后扣，无前置费 | 稳定后正式开店 |

## 三、按阶段的坑清单

### ① 入驻坑
- [ ] 类目必须精准：淘宝虚拟商品归入「教育培训/软件服务/虚拟服务/数字内容」，挂"其他"= 降权/封店
- [ ] 类目、标题、详情页三者一致（标题含"视频教程""PDF讲义"等关键词）
- [ ] 教育类目可能要求讲师证书/版权授权书，提前准备
- [ ] 灰色类目绝对不碰：代写论文、代注册、代开票、代刷——能卖出去也会被监控，轻下架重封号

### ② 流量坑（新手亏损第一名）
- [ ] 新店没有免费流量是常态，先靠内容引流（小红书/知乎/闲鱼鱼塘）而非付费投放
- [ ] **自然流量模型跑通之前，一分钱广告费都不要花**
- [ ] 不刷单：平台风控必抓，抓到降权+扣保证金
- [ ] 淘宝用"自动发货"功能（邮箱/网盘链接），手动发货易引发纠纷、拉低评分

### ③ 交易纠纷坑
- [ ] 虚拟商品详情页必须写明"一经售出不退换"，否则无法拒绝退货申请
- [ ] 保留所有交付记录（发货凭证、网盘链接、聊天记录），纠纷举证用
- [ ] 虚拟商品退款时平台已扣的服务费不退——定价时预留这部分损耗

### ④ 平台抽成坑
- [ ] 定价公式里显式包含平台费率（闲鱼 1.6% / 淘宝虚拟类 5%-10%）
- [ ] 定期（每季度）检查平台费率公告，费率上调后立即重算毛利

### ⑤ 虚拟商品特有坑
- [ ] 防盗版只能缓解不能根治：授权码、联网验证、水印、分批交付
- [ ] 接受"第二天就会被倒卖"的心理预期，靠持续更新和服务增值保持竞争力
- [ ] 重要客户尽早沉淀到私域（微信），平台账号被封时资产不丢

## 四、个人开店风险登记簿

| 风险 | 严重度 | 对策 |
|---|---|---|
| 封号/清退 | ⚠️ 最高 | 不碰灰产、背熟规则红线、客户沉淀私域 |
| 无限责任 | 中 | 收入稳定后注册**个体工商户**（淘宝支持个体户开店，可对公收款、开发票） |
| 税务 | 中 | 小规模纳税人月销售额 10 万以下免增值税；前期试水碰不到线 |
| 平台依赖 | 中 | 多平台挂单 + 私域，鸡蛋分篮 |
| 保证金占用 | 低 | 可退，不算真风险 |

## 五、低风险试错路径（推荐顺序）

1. **闲鱼起步（0 元）**：挂 AI 服务/小工具，用"咨询""定制"话术规避敏感词，测真实需求和定价。月≤10笔且≤1万时免服务费
2. **有稳定询盘 → 上微店**：承接微信私域，做复购和转介绍
3. **月入稳定过万 → 开淘宝店**：办个体户、交保证金、正式品牌化
4. 全程不投付费推广，直到自然流量模型跑通

## 六、动手前最终核对

- [ ] 第一个月预算上限 1000 元
- [ ] 选定的类目和商品形态在平台规则允许范围内（对照淘宝类目规范最新版）
- [ ] 详情页含"一经售出不退换"+交付方式说明
- [ ] 定价已含平台费率 + 退款损耗预留
- [ ] 私域承接通道已就绪（微信号/社群）
- [ ] 知道封号申诉入口和保证金退还流程
